# AI Speaker Notes MVP

Feasibility MVP untuk membuktikan pipeline **PPTX → parse → generate test notes → write-back → integrity check → download** sebelum AI diaktifkan.

## Kenapa arsitekturnya seperti ini?

MVP sengaja memakai **FastAPI + HTML/CSS/Vanilla JS**. UI dibuat tipis; domain logic dipisahkan ke service agar frontend bisa diganti React/Vue/Next.js tanpa membongkar core PowerPoint. `NotesGenerator` juga merupakan boundary tersendiri, sehingga `DummyNotesGenerator` nanti dapat diganti provider AI tanpa mengubah parser, API, atau notes writer.

## Fitur MVP 0.1

- Upload `.pptx` maksimum 50 MB (dapat dikonfigurasi).
- Validasi format berdasarkan struktur OOXML/ZIP, bukan extension saja.
- Guard terhadap path traversal, macro payload, ukuran ekstraksi abnormal, dan compression bomb sederhana.
- Parse judul, text box, dan tabel dari semua slide.
- Generate deterministic dummy speaker notes untuk membuktikan pipeline tanpa biaya API AI.
- Write-back speaker notes ke **working copy**, tidak pernah menimpa file upload asli.
- Integrity check: jumlah slide serta visible text/table dibandingkan sebelum dan sesudah save.
- Job status + progress polling.
- Download output `.pptx`.
- Retention cleanup untuk job lama.
- Security headers, same-origin frontend, no external CDN.
- Health endpoints (`/api/v1/health/live`, `/api/v1/health/ready`).
- Optional slide renderer (LibreOffice + `pdftoppm`) sudah dipisahkan untuk fase vision AI.

## Quick start — Windows PowerShell

Dari folder project:

```powershell
.\scripts\setup.ps1
.\scripts\run.ps1
```

Buka `http://127.0.0.1:8000`.

Alternatif manual:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

## Quick start — Linux/macOS

```bash
./scripts/setup.sh
./scripts/run.sh
```

## Test

```powershell
.\.venv\Scripts\Activate.ps1
pytest
ruff check .
```

## Konfigurasi

Salin `.env.example` menjadi `.env`. Yang penting:

- `MAX_UPLOAD_MB=50`
- `JOB_RETENTION_HOURS=24`
- `RENDER_SLIDES=false`

`RENDER_SLIDES` sengaja `false` pada MVP 0.1 agar aplikasi bisa berjalan tanpa LibreOffice/Poppler. Saat vision AI mulai diintegrasikan, aktifkan renderer setelah dependensinya tersedia.

## Output per job

```text
storage/jobs/<uuid>/
├── input.pptx
├── job.json
├── presentation.json
└── result-with-notes.pptx
```

File input disimpan dengan nama internal tetap, bukan nama yang dikirim user, untuk menghindari path injection.

## Verifikasi satu perintah

Setelah setup:

```powershell
.\scripts\verify.ps1
```

Script menjalankan automated tests lalu menghasilkan `examples/demo-output.pptx`. Buka file itu di Microsoft PowerPoint dan cek bagian Notes untuk memastikan write-back benar-benar terbaca oleh PowerPoint.
