Cara menggunakan AI Speaker Notes

How to use AI Speaker Notes

Alurnya sengaja dibuat sederhana: upload, pilih pengaturan, proses, review, lalu download. Sistem menangani banyak edge case PowerPoint di belakang layar.

The workflow is intentionally simple: upload, configure, process, review, then download. The system handles many PowerPoint edge cases behind the scenes.

6 langkah utama

6 main steps

Upload .pptx

Pilih file PowerPoint maksimum {{ max_upload_mb }} MB. File asli tidak diubah.

Choose a PowerPoint file up to {{ max_upload_mb }} MB. The original stays untouched.

Pilih bahasa dan audiensChoose language and audience

Gunakan preset Mahasiswa untuk penjelasan yang lebih mudah, atau Akademik untuk gaya yang lebih formal.

Pilih Text-only atau VisionChoose Text-only or Vision

Vision direkomendasikan untuk grafik, diagram, dan image-only slide. Maksimum {{ max_vision_slides }} target slide per job.

Vision is recommended for charts, diagrams, and image-only slides. Up to {{ max_vision_slides }} target slides per job.

Proses dan tunggu validasiProcess and wait for validation

Aplikasi melakukan preflight, rendering, generation, write-back, dan integrity check.

The app runs preflight, rendering, generation, write-back, and integrity checks.

Review hasilReview the result

Periksa warning, visual coverage, dan slide yang memakai fallback. AI tetap dapat salah.

Check warnings, visual coverage, and fallback slides. AI can still be wrong.

Download / Chat AI

Unduh PPTX atau buka Chat AI untuk menjelaskan slide tertentu, meringkas, atau rewrite notes.

Download the PPTX or open AI Chat to explain a slide, summarize it, or rewrite notes.

Batas penggunaan v0.2.8

v0.2.8 usage limits

AI JOB

≤ {{ max_ai_slides }} slides

Deck lebih besar sebaiknya dipecah agar biaya, latency, dan konteks tetap terkendali.

Split larger decks to keep cost, latency, and context predictable.

VISION

≤ {{ max_vision_slides }} target slides

Text-only masih bisa dipakai untuk deck yang dominan teks.

Text-only remains available for text-heavy decks.

INPUT

Bounded

Instruksi, custom word count, chat message, dan total konteks punya batas untuk menghindari overload.

Instructions, word count, chat messages, and total context are bounded to prevent overload.

Troubleshooting

“Slide tidak punya teks” tetapi ada gambar

Gunakan Vision. v0.2.8 mendeteksi image-only slide dan tidak menganggapnya kosong hanya karena tidak ada textbox.

Use Vision. v0.2.8 detects image-only slides and does not treat them as blank just because there is no textbox.

Hidden slides

Hidden slide dinormalisasi untuk proses render agar numbering tidak bergeser. Jika satu slide gagal, sistem mencoba recovery per slide.

Hidden slides are normalized for rendering so numbering stays aligned. If one slide fails, the system attempts per-slide recovery.

External / linked image

Aplikasi tidak mengambil URL eksternal secara otomatis karena alasan keamanan. Embed gambar ke dalam PowerPoint jika visual wajib dianalisis.

The app does not automatically fetch external URLs for security. Embed required images inside the PowerPoint.

File ditolak

Macro, ZIP/PPTX mencurigakan, path traversal, decompression bomb, dan embedded OLE/package object diblokir secara default.

Macros, suspicious ZIP/PPTX packages, path traversal, decompression bombs, and embedded OLE/package objects are blocked by default.
