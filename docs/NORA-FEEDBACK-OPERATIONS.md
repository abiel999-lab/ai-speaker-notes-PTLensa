# Feedback operations

Status: form and Cekat Feedback classification are live. This register is a manual operating template, not an automatic export/dashboard. No real customer conversations have been imported; empty rows do not mean zero customer feedback.

Daily review: open Cekat inbox filtered by Feedback and the support mailbox subjects Feedback / feature request. For each item retain the existing conversation ID or SUP reference; select Notes/Presentation/Translator, summarize without documents or personal details, assign owner, status and next action. Use the original protected inbox for full messages. Do not copy email addresses or confidential documents into the register or GitHub.

Priority: urgent security/billing access complaints are escalated to the responsible team; reproducible broken functionality is handled before usability suggestions. Feature ideas go to the product backlog. Keep Billing/Technical/Account labels where applicable; Feedback can coexist. Statuses: New, Reviewing, Needs information, Planned, Fixed, Closed. Close only after action is verified; do not claim an automatic ticket or guaranteed delivery time.

Agent: Actia Carbon is the existing human agent. Existing auto status schedule remains unchanged. Weekly summary should include reviewed/new/unresolved counts only after counting the chosen inbox/date range, top themes, changes shipped and remaining blockers. Do not invent totals from Preview QA.
