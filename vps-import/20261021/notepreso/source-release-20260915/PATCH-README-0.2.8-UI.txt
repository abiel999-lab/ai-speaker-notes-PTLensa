AI Speaker Notes v0.2.8 - Bilingual + Responsive UI patch

Cara pakai:
1. Stop aplikasi (Ctrl+C).
2. Extract isi ZIP ini langsung ke folder ai-speaker-notes-mvp.
3. Pilih Replace/Overwrite jika Windows meminta konfirmasi.
4. Jalankan lagi: .\scripts\run.ps1
5. Di browser lakukan hard refresh: Ctrl+Shift+R

Patch ini hanya berisi file UI yang berubah. Tidak berisi .env, API key, storage job, atau virtual environment.

Perubahan utama:
- Home bilingual ID/EN lebih lengkap, termasuk label, help text, select options, warning, metrics, dan placeholder.
- Chat bilingual diperbaiki untuk teks dinamis.
- How to Use melengkapi bagian EN yang sebelumnya masih Indonesia.
- Favicon/meta viewport konsisten di Dashboard, Chat, How to Use, Legal, dan Login.
- Responsive hardening untuk HP/tablet/desktop, portrait/landscape, touch target, navigation, forms, chat, legal, login, results, dan history.
